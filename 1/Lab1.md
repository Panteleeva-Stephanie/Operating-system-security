2.1 Перемещение по файловой системе

2.1.1. Авторизация, запуск терминала
Ctrl + Alt + F3 - вход в текстовую виртуальную консоль (TTY - TeleTYpe
Ctrl + Alt + F2 - выход из текстовой виртуальной консоли
через окно запуска команд: Alt + F2, для дистрибутива Debian ввести команду gnome-terminal
(или универсальную xterm)
Ввод логина и пароля (авторизация) для доступа к системе в графическом режиме

2.1.2. Имя текущего пользователя, текущий каталог (абсолютный путь от /)
whoami (или echo $USER)
pwd

2.1.3. Переход в корневой каталог (/), переход в каталог уровня выше, переход в домашнюю директорию
cd /
cd ..
cd ~

2.1.4. Вывод списка файлов текущего каталога - команда ls (list)
Флаги:
-a - вывод в том числе и скрытых файлов
-1 - вывод по 1 файлу в каждой строке
-m - вывод файлов через запятую
-l - вывод с последовательным указанием характеристик файла
-h - вывод файла с размером, понятным человеку

2.1.5. Вывод списка файлов каталога /etc
ls -la /etc 
cd /etc && ls 

2.1.6. Перейти в домашний каталог текущего пользователя
cd 
cd ~
cd $HOME или cd $home

2.1.7. Вывод списка файлов и каталогов текущего каталога
ls -1d .* - вывод в столбик только скрытых файлов и директорий
ls -ap - вывод всех файлов и директорий, причём в конце названий директорий для наглядности ставится /

2.1.8 Вывод списка файлов и каталогов (включая скрытые) с информацией о владельце и правах доступа
ls -hal - вывод списка всех (в т.ч. скрытых) файлов в столбик с указанием их характеристик и размеров в человекочитаемом виде

2.2. Работа с файловой системой

2.2.1 Создать подкаталог fruits в домашнем каталоге текущего пользователя
mkdir ~/fruits
ИЛИ cd && mkdir fruits

2.2.2 Перейти в корневой каталог и из него создать в домашнем каталоге подкаталог animals
cd / && mkdir ~/animals
Проверка: ls -1p ~/

2.2.3 В подкаталоге корневого каталога, предназначенного для хранения временных файлов, создать пустой файл temp
touch /tmp/temp
Проверка: ls -1p /tmp/

2.2.4 Используя команду echo и перенаправление вывода записать в файл temp строку «Hello». Второй такой командой дописать строку «world». Открыть файл при помощи текстового редактора nano, добавить в конец три знака «!», сохранить запись и выполнить выход из редактора
echo "Hello" >> /tmp/temp
echo "world" >> /tmp/temp
nano /tmp/temp
В nano: Ctrl + O, Enter, Ctrl + X

2.2.5 Перейти в каталог fruits и создать в нем пустые файлы apple, banana, pineaple, lion (используйте соединение команд при помощи &&)
cd ~/fruits/ && touch apple banana pineaple lion
ИЛИ cd ~/fruits/ && :| tee apple banana pineaple lion

2.2.6 Находясь в каталоге fruits, создать в каталоге animals пустые файлы cat.txt, dog.txt, elephant.txt одной командой
cd ~/animals/ && touch cat.txt dog.txt elephant.txt
ИЛИ touch ../animals/{cat.txt,dog.txt,elephant.txt}

2.2.7 Вывести все файлы каталога fruits, имя которых начинается с буквы a
ls ~/fruits/a*

2.2.8 Вывести все файлы каталога fruits, имя которых заканчивается буквой e
ls -1 ~/fruits/*e

2.2.9 Вывести все файлы каталога fruits, имя которых содержит буквы a и n
ls ~/fruits/ | grep 'a' | grep 'n'

2.2.10 Скопировать файл с учетными записями пользователей системы в домашний каталог текущего пользователя. Выведите на экран количество
строк в этом файле. В домашнем каталоге создать символьную ссылку на этот файл. Определить номер inode этой ссылки
cp /etc/passwd ~ && wc -l /etc/passwd && ln -s ~/passwd ~/passwd_link && ls -id ~/passwd_link

2.2.11 Вывести содержимое файла /etc/issue на экран
cat /etc/issue

2.2.12 Скопировать файл /etc/issue в файл apple с заменой содержимого, выполнить проверку
cp /etc/issue ~/fruits/apple && cat ~/fruits/apple

2.2.13 Переместить файл lion в каталог animals
mv ~/fruits/lion ~/animals/

2.2.14 Исправить опечатку в имени файла pineaple
mv ~/fruits/pineaple ~/fruits/pineapple 

2.2.15 В домашнем каталоге создать жесткую ссылку на файл истории команд командной оболочки. Вывести информацию о количестве жестких ссылок на этот файл
ln ~/.bash_history ~/bash_history_HardLink && stat -c %h ~/.bash_history 

2.2.16 Удалить каталог fruits
rm -r ~/fruits/

2.2.17 Вывести на экран содержимое файла лога загрузки операционной системы
sudo cat /var/log/boot.log 
ИЛИ sudo dmesg
ИЛИ journalctl -b


2.3. Механизм конвейеров

2.3.1 Вывести на экран отсортированный по алфавиту список пользователей операционной системы
cut -d: -f1 /etc/passwd | sort

2.3.2 Вывести на экран число пользователей, у которых командной оболочкой является bash
grep -c '/bin/bash' /etc/passwd

2.3.3 Вывести на экран только имена пользователей, использующих командную оболочку bash, отсортировав их по алфавиту в обратном порядке
grep '/bin/bash' /etc/passwd | cut -d: -f1 | sort -r

2.3.4 Вывести на экран имена пользователей и используемую ими командную оболочку (в две колонки)
cut -d: -f1,7 /etc/passwd | tr ':' '\t'


2.4 Получение прав суперпользователя
sudo su
ИЛИ su - (нужен пароль суперпользователя root)
ИЛИ sudo -i

2.4.1 Вывести на экран содержимое файла с паролями пользователей, выполняя команду от имени текущего пользователя
cat /etc/passwd

2.4.2 Вывести список групп текущего пользователя на экран. Установить,
входит ли ваш пользователь в группу администраторов? Если нет, завершить
сеанс текущего пользователя и авторизоваться как root. Включить пользователя
в группу администраторов командой usermod
groups && sudo usermod -aG sudo debian

2.4.3 От имени суперпользователя (sudo <>) выполнить команду из п. 2.4.1
sudo -i | cat /etc/passwd

2.4.4 Вывести список администраторов всех пользователей, входящих в группу администраторов
getent group sudo ИЛИ getent group sudo | cut -d: -f4


2.5 Поиск файлов и каталогов

2.5.1 Изучить доступные опции утилиты find
Синтаксис команды: find [где_искать] [критерии_поиска] [что_сделать]. Если путь не указан, поиск ведется в текущей директории

2.5.2 Найти все файлы и каталоги, имя которых содержит подстроку pass с учётом регистра
find / -name "*pass*"

2.5.3 Найти все файлы и каталоги, имя которых содержит подстроку pass без учёта регистра
find / -iname "*pass*"

2.5.4 Найти все файлы и каталоги, имя которых содержит подстроку pass с учётом регистра. Начать поиск с / и ограничиться глубину одним уровнем
find / -maxdepth 1 -name "*pass*"

2.5.5 Найти все файлы и каталоги, имена которых оканчиваются на .bin. Выполнить поиск в каталоге /home и всех его подкаталогах
find /home -name "*.bin"

2.5.6 Найти все обычные файлы и только их, имена которых оканчиваются на .bak, и удалить их
find / -type f -name "*.bak" -delete

2.5.7 Найти все обычные файлы и только их, имена которых оканчиваются на .txt или .sh
find / -type f \( -name "*.sh" -o -name "*.txt" \)

2.5.8 Найти все обычные файлы и только их в текущем каталоге и всех его подкаталогах. Для каждого файла вывести только следующие сведения: имя файла без пути, имя владельца, имя группы владельца, количество жёстких ссылок и размер в байтах
find . -type f -printf "%f %u %g %n %s\n"

2.5.9 Найти все пустые каталоги внутри текущего каталога, включая вложенные. Сам текущий каталог в результат не включать
find . -mindepth 1 -type d -empty

2.5.10 Найти и удалить все пустые каталоги внутри текущего каталога, включая вложенные. Сам текущий каталог сохранить
find . -mindepth 1 -type d -empty -delete

2.5.11 Найти и удалить все пустые обычные файлы и только их. Пустым считать файл размером 0 байт
find . -type f -size 0 -delete

2.5.12 Найти все обычные файлы и только их в текущем каталоге и всех его подкаталогах, у которых количество жёстких ссылок больше одной
find . -type f -links +1

2.5.13 Найти все файлы и каталоги в /etc и его подкаталогах, не принадлежащие пользователю root
find /etc ! -not -user root

2.5.14 Найти все обычные файлы и только их, имена которых не оканчиваются на .sh. Файлы без расширения также должны попадать в результат
find . -type f ! -name "*.sh"

2.5.15 Найти все обычные файлы и только их, у которых количество жёстких ссылок больше двух
find / -type f -links +2

2.5.16 Найти все обычные файлы и только их в /usr/bin и его подкаталогах, сохранённая метка последнего доступа к которым (atime) указывает на время более 90 суток назад
find /usr/bin -type f -atime +90

2.5.17 Найти все обычные файлы и только их в каталогах /usr/bin и /usr/share, включая их подкаталоги, содержимое которых изменялось в течение последних 10 суток. Использовать время изменения содержимого (mtime)
find /usr/bin /usr/share -type f -mtime -10

2.5.18 Найти и удалить все обычные файлы и только их в /tmp и его подкаталогах, последнее изменение содержимого которых произошло более 14 суток назад. Использовать время изменения содержимого (mtime)
find /tmp -type f -mtime +14 -delete
